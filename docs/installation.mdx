MCP Atlassian can be installed using several methods. Choose the one that best fits your workflow.

<Note>
Every method below installs from the Git repository at https://github.com/endofcake/mcp-atlassian or builds the container image from a clone.
</Note>

## uvx (Recommended)

The simplest way to run MCP Atlassian without permanent installation using [uvx](https://docs.astral.sh/uv/guides/tools/):

```bash
# Run directly (clones and builds on first use, cached for subsequent runs)
uvx --from git+https://github.com/endofcake/mcp-atlassian mcp-atlassian --help

# Run with a specific Python version if needed
uvx --python=3.12 --from git+https://github.com/endofcake/mcp-atlassian mcp-atlassian --help
```

    ```json
            "JIRA_URL": "https://your-company.atlassian.net",
    ```

    Bitbucket Data Center with an access token:

    ```json

      "mcpServers": {
    ```

## Docker

Docker provides an isolated environment and is recommended for production deployments or when you need specific version control.

Build the image from a clone of the repository:

```bash
git clone https://github.com/endofcake/mcp-atlassian.git
cd mcp-atlassian
docker build -t mcp-atlassian:local .
```

Then run it with environment variables. Jira Cloud:

```bash
docker run --rm -i \
  -e JIRA_URL=https://your-company.atlassian.net \
  -e JIRA_USERNAME=your.email@company.com \
  -e JIRA_API_TOKEN=your_api_token \
  mcp-atlassian:local
```

Bitbucket Data Center with an access token:

```bash
docker run --rm -i \
  -e BITBUCKET_URL=https://bitbucket.your-company.com \
  -e BITBUCKET_OAUTH_ACCESS_TOKEN=your_bitbucket_access_token \
  mcp-atlassian:local
```

```json
        "CONFLUENCE_URL": "https://your-company.atlassian.net/wiki",
        "CONFLUENCE_USERNAME": "your.email@company.com",
        "CONFLUENCE_API_TOKEN": "your_confluence_api_token",
        "JIRA_URL": "https://your-company.atlassian.net",

```

Drop the variables for any service you do not use. See [Configuration](/docs/configuration) for more Docker options including environment files.

## uv

Install the package into a Python environment with [uv](https://docs.astral.sh/uv/), for development or when you need it importable:

```bash
# Install into the current environment
uv pip install git+https://github.com/endofcake/mcp-atlassian

# Include this extra when PAC/WPAD proxy routing is enabled
uv pip install "mcp-atlassian[wpad] @ git+https://github.com/endofcake/mcp-atlassian"

# Or add it to a uv-managed project
uv add git+https://github.com/endofcake/mcp-atlassian

# Run the server
mcp-atlassian --help
```

## From Source

For development or contributing:

```bash
git clone https://github.com/endofcake/mcp-atlassian.git
cd mcp-atlassian
uv sync --frozen --all-extras --dev
uv run mcp-atlassian --help
```

See [CONTRIBUTING.md](https://github.com/endofcake/mcp-atlassian/blob/main/CONTRIBUTING.md) for development setup details.
