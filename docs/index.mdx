Model Context Protocol (MCP) server for Atlassian products: Jira, Confluence, and Bitbucket Data Center. Jira and Confluence work on both Cloud and Server/Data Center. Bitbucket support covers Data Center.

## About this fork

This is a fork of [sooperset/mcp-atlassian](https://github.com/sooperset/mcp-atlassian) that adds Bitbucket Data Center as a third service. Install it with `uvx --from git+https://github.com/endofcake/mcp-atlassian mcp-atlassian` or build the container image yourself (see [Installation](/docs/installation)). Bitbucket bugs, and bugs in this fork, belong in [this repository's issues](https://github.com/endofcake/mcp-atlassian/issues). Jira and Confluence bugs that also reproduce on upstream belong upstream.

## Example Usage

Ask your AI assistant to:

- **"Find issues assigned to me in PROJ project"**
- **"Search Confluence for onboarding docs"**
- **"Create a bug ticket for the login issue"**
- **"Update the status of PROJ-123 to Done"**
- **"List open pull requests in PROJ/my-repo and summarise the diff of #42"**

## Compatibility

| Product | Deployment | Support |
|---------|------------|---------|
| Confluence | Cloud | Fully supported |
| Confluence | Server/Data Center | Supported (v6.0+) |
| Jira | Cloud | Fully supported |
| Jira | Server/Data Center | Supported (v8.14+) |
| Bitbucket | Cloud | Not supported |
| Bitbucket | Data Center | Supported (v9.0+, OAuth 2.0) |
