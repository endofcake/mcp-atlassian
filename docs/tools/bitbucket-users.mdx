### Get Bitbucket Current User

Get the Bitbucket Data Center user the server is acting as.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `refresh` | `boolean` | No | Resolve the caller's identity again instead of reusing the value cached on this client. Only needed on a long-lived client after the account has been renamed. |
